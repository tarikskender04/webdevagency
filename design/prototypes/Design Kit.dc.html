03

Imagery

Rendered objects on white. No photography, no illustration, no stock.

Family A — dispersion Chromatic glass Refractive solids that split light into the full spectrum. Dark core, rainbow edges. Use where the page needs weight and drama: hero, section covers, the one image on a case study.
Family B — gradient solids Cool spectrum forms Smooth shapes running teal to deep blue. Quieter, and closer to the azure palette. Use for supporting spots: feature rows, cards, list markers, empty states.
The rules One object per view.
Always on white, never on a tint.
No drop shadow — the object carries its own light.
The object is the only saturated thing on the screen; everything around it stays ink, slate and azure.
Mix families across a page, never inside one view.
Generative counterparts — same language, rendered live
Strands Woven light on the kit's three blues. Section covers and footers, behind type, never under body copy.
Prism A live dispersion object in light mode. The animated stand-in for family A when a still render is not available.

Rules

Used for documentation, case-study chapters and long settings screens — anywhere the top bar would run out of room.

  • Branches are Line #D4E2EC; the drawn path is Azure. Only the active row is coloured.
  • Rows 38px with the 24px kit icons at 16px, 1.5px stroke.
  • One section open by default. The fold is 300ms, the line draws in 400ms — no bounce.
  • Never pair with the floating glass bar on the same screen.
